# Smart Parking Assistant System

## Overview
Designed and developed a Smart Parking Assistant System using an Arduino Uno and ultrasonic sensors to detect vehicle occupancy in parking slots. The system provides real-time slot status through LED indicators, helping drivers identify available spaces while demonstrating embedded programming, sensor interfacing, and parking automation.

## Components Used
- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- LEDs
- Breadboard
- Jumper Wires
- Power Supply

## Features
- Automatic parking slot detection
- Real-time LED indication
- Contactless vehicle detection
- Low-cost parking automation

## Working Principle
The ultrasonic sensor continuously measures the distance to detect the presence of a vehicle. The Arduino processes the sensor readings and controls LEDs to indicate whether a parking slot is occupied or vacant.
